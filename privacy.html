Privacy Policy: Oddly True Uploader

Last updated 2026-11-06

Oddly True Uploader ("the tool") is a private tool used only by the owner of the YouTube channel "Oddly True" to upload the channel's own original animated videos and read the channel's own analytics. It has no other users.

YouTube API Services

The tool uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using the tool you agree to be bound by the YouTube Terms of Service.

Google Privacy Policy

Data obtained through YouTube API Services is also subject to the Google Privacy Policy (https://policies.google.com/privacy).

What data we access, and why

  • An OAuth access/refresh token for the Oddly True channel (scopes youtube.upload, youtube, yt-analytics.readonly).
  • Our own channel's video metadata (titles, descriptions, upload status) and our own analytics reports.

Used only to upload our own videos, set their titles, descriptions and thumbnails, and measure their performance. No data from other YouTube users or channels is collected.

Storage and sharing

Tokens and analytics are stored only on the owner's private computer. Nothing is sold, shared, or transferred to third parties. No cookies or tracking are used on this website.

Data deletion and revoking access

  • Access can be revoked at any time at https://myaccount.google.com/permissions (Google security settings page).
  • When access is revoked, or on request by email, the stored token and all stored API data are deleted within 7 days.
  • Stored API data is refreshed or deleted at least every 30 days, as required by the YouTube API Services policies.
